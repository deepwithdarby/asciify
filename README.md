# Convert Images into ASCII Art with the power of Python

This is a simple web app to convert images into ASCII art. It is based on the [asciify](https://github.com/RameshAditya/asciify) tool.

## How to use
1. Upload an image using the image upload component.
2. The ASCII art will be displayed in the textbox below.
